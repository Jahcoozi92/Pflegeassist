# Pflegeassist
Interaktives, barrierefreies HTML-Flussdiagramm für Altenpflegefachkräfte, das verschiedene realitätsnahe Einrichtungsszenarien (z.B. E-Rollstuhl-Panne, Personalausfall am Wochenende) mit Auswahloptionen zur Entscheidungsunterstützung abbildet, sich nach Tageszeit/Wochentag anpasst und um neue Szenarien erweitert werden kann.
